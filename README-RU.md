# Device Tool V2.0

**Device Tool V2.0** — это удобный инструмент для управления Android-устройствами через ADB и Fastboot. Позволяет выполнять различные операции: от поиска устройства до прошивки и управления файлами.

## ⚠️ ВАЖНЫЕ ПРЕДУПРЕЖДЕНИЯ

| Команда | Риск |
|---------|------|
| **2** (Reflashing) | Полная перезапись системы — высокий риск "кирпича" |
| **4** (Unlock bootloader) | Сбрасывает телефон до заводских, аннулирует гарантию |
| **5** (Lock bootloader) | Сбрасывает телефон до заводских |
| **6** (Factory reset) | Удаляет все данные с телефона |

**Перед использованием этих команд убедитесь, что вы знаете, что делаете!**

## 🔧 Требования

- Windows 7 / 8 / 10 / 11
- Подключённое Android-устройство с включённой USB-отладкой

---

## 🛠 Как включить USB-отладку

1. Зайдите в **Настройки → О телефоне**
2. Нажмите 7 раз на **Номер сборки**
3. Вернитесь в **Настройки → Для разработчиков**
4. Включите **USB-отладку**
